# 躲避陨石游戏

一款基于 Pygame 的 2D 射击/躲避类小游戏。

## 游戏基本信息

| 项目 | 内容 |
|------|------|
| 游戏名称 | 躲避陨石 |
| 屏幕尺寸 | 800 × 600 像素 |
| 帧率 | 60 FPS |
| 游戏类型 | 射击/躲避类 |

---

## 玩家操作方式

### 键盘操作

| 按键 | 功能 |
|------|------|
| **← 左箭头** | 飞船向左移动 |
| **→ 右箭头** | 飞船向右移动 |
| **空格键** | 发射子弹（需获得子弹道具） |
| **P 键** | 暂停 / 继续游戏 |
| **R 键** | 游戏结束后重新开始 |
| **ESC 键** | 取消暂停状态 |

### 鼠标操作
- 点击按钮：开始游戏、继续游戏、重新开始、退出游戏

### 特殊操作（已优化）
- **飞船移动时自动发射子弹**：无需按空格键，左右移动时自动连续发射
- **子弹冷却时间**：3 帧（约 0.05 秒）
- **子弹杀伤力**：2 点伤害

## 核心游戏系统

### 1. 飞船系统
- **位置**：底部居中 (800×600 屏幕)
- **尺寸**：60 × 40 像素
- **移动速度**：7 像素/帧
- **外观**：蓝色三角形 + 红色矩形驾驶舱

### 2. 子弹系统
- **类型**：黄色矩形子弹
- **速度**：向上 10 像素/帧
- **冷却时间**：3 帧（约 0.05 秒）
- **杀伤力**：2 点伤害
- **触发条件**：获得子弹道具后，移动时自动发射

### 3. 陨石系统（4 种类型）

| 类型 | 尺寸 | 速度 | 生命值 | 分数 | 颜色 | 特殊能力 |
|------|------|------|--------|------|------|----------|
| **小型** | 20-30px | 6-10 | 1 | 5 | 浅棕色 | - |
| **中型** | 35-50px | 4-7 | 2 | 10 | 棕色 | - |
| **大型** | 55-75px | 2-4 | 3 | 20 | 深棕色 | - |
| **分裂** | 40-55px | 3-6 | 2 | 15 | 红棕色 | 摧毁后分裂为 2-3 个小型陨石 |

**视觉效果**：
- 椭圆形外观
- 旋转动画
- 显示剩余生命值（如 "2/2"）
- 受伤时颜色变暗

### 4. 道具系统（3 种类型）

| 道具 | 颜色 | 图标 | 持续时间 | 效果 |
|------|------|------|----------|------|
| **护盾** | 蓝色 (50,150,255) | 🛡️ "盾" | 5 秒 (300 帧) | 免疫陨石碰撞，碰撞时摧毁陨石 |
| **子弹** | 黄色 (255,215,0) | ⚡ "弹" | 10 秒 (600 帧) | 可发射子弹，移动时自动发射 |
| **减速** | 绿色 (50,205,50) | ⏱️ "慢" | 7 秒 (420 帧) | 陨石下落速度减半 |

**视觉效果**：
- 椭圆形外观
- 脉冲动画（大小变化）
- 旋转效果
- 左上角显示状态条（进度 + 剩余时间）

### 5. 生命值系统
- **初始生命**：3 条
- **最大生命**：3 条
- **碰撞后果**：
  - 有护盾时：护盾吸收伤害，陨石被摧毁
  - 无护盾时：生命 -1，显示警告闪烁 + 消息提示
  - 生命为 0 时：游戏结束

### 6. 得分系统
- **基础得分**：
  - 摧毁陨石：按类型 5-20 分
  - 躲避陨石（飞出屏幕）：10 分
- **连击加成**：连击数越高，得分倍数越高
- **最高分记录**：自动保存到 `high_score.txt`

### 7. 连击系统
- **触发条件**：连续摧毁/躲避陨石
- **超时时间**：2 秒无操作则重置
- **倍数里程碑**：

| 连击数 | 得分倍数 | 显示颜色 |
|--------|----------|----------|
| 1-4 | 1.0x | 白色 |
| 5-9 | 1.2x | 浅蓝色 |
| 10-19 | 1.5x | 浅红色 |
| 20-49 | 2.0x | 橙色 |
| 50-99 | 3.0x | **金色** |
| 100+ | 5.0x | **紫色** |

### 8. 难度/等级系统
- **初始等级**：1
- **升级条件**：每获得 500 分提升 1 级
- **难度提升**：
  - 陨石速度增加
  - 陨石生成频率增加
  - 等级 5+：陨石生命值 ×1.2
  - 等级 10+：陨石生命值 ×1.5
- **升级提示**：显示"等级 X！难度提升！"消息

## 视觉特效系统

### 1. 粒子效果系统
- **引擎尾迹**：飞船移动时产生蓝色粒子
- **爆炸效果**：陨石摧毁时产生橙/黄/红色粒子

- **中等震动**：陨石爆炸、护盾吸收碰撞
- **强烈震动**：飞船碰撞、游戏结束

### 3. 其他视觉效果
- **星空背景**：滚动星空 + 闪烁星星
- **护盾效果**：三角形护罩 + 闪烁圆环
- **警告闪烁**：生命值减少时红色边框闪烁
- **死亡闪烁**：游戏结束前红色全屏闪烁
- **浮动文字**：得分消息、生命值消息、道具获得消息

## 技术栈评估

### 1. 核心技术

| 类别 | 技术 | 版本 | 说明 |
|------|------|------|------|
| **编程语言** | Python | 3.12.7 | 主开发语言 |
| **游戏框架** | Pygame | 2.6.1 | 2D 游戏开发框架 |
| **音频合成** | Python `array` 模块 | - | 原生音频数据处理 |
| **文字渲染** | Pygame `font` 模块 | - | 系统字体渲染 |

### 2. 渲染系统技术

#### 2.1 2D 图形渲染
- **Surface 渲染**：使用 `pygame.Surface` 作为主要渲染对象
- **透明度处理**：
  - `pygame.SRCALPHA`：per-pixel alpha 格式
  - `colorkey`：`font.render()` 返回的 Surface 使用 colorkey
  - `set_alpha()`：整体透明度设置
  - `convert_alpha()`：格式转换（解决透明度问题的关键）
- **图形变换**：`pygame.transform.scale()` 缩放变换
- **像素级操作**：`pygame.surfarray` 直接操作像素数据（用于精确的 alpha 控制）

#### 2.2 文字渲染技术
```
font.render(text, antialias, color)
    ↓
返回带 colorkey 的 Surface（背景为 colorkey）
    ↓
convert_alpha() 转换为 per-pixel alpha
    ↓
surfarray.pixels_alpha() 精确控制每个像素的 alpha 值
```

**注意**：`font.render()` 与 `set_alpha()` 的组合存在兼容性问题，这是导致黄色/红色遮挡块的根本原因。

### 3. 音频系统技术（自研合成引擎）

#### 3.1 架构特点
- **零依赖音频文件**：完全使用代码生成音频
- **回退机制**：优先加载外部文件，失败则自动生成合成音效
- **双通道立体声**：单声道数据复制为立体声

#### 3.2 音频波形类型

| 波形类型 | 实现类/方法 | 用途示例 |
|----------|-------------|----------|
| **正弦波** | `generate_sine_wave()` | 射击、按钮点击 |
| **方波** | `generate_square_wave()` | 复古游戏音效 |
| **锯齿波** | `generate_sawtooth_wave()` | 丰富的谐波 |
| **白噪声** | `generate_white_noise()` | 爆炸、碰撞 |

#### 3.3 合成音效技术

**参数化设计**：
- **频率包络**：随时间变化的频率（如射击音效：800Hz → 500Hz）
- **音量包络**：随时间变化的音量（如攻击、衰减、释放）
- **多波混合**：多种波形叠加产生丰富音色

**示例：升级音效（4 音符琶音）**：
```python
# A4 (440Hz) → C#5 (554Hz) → E5 (659Hz) → A5 (880Hz)
# 基波 + 2次谐波 + 3次谐波 叠加
```

**示例：背景音乐**：
- 旋律模式：8 音符循环
- 贝斯模式：8 音符循环
- Pad 层：3 个低音正弦波叠加
- 每个音符带音量包络

#### 3.4 音频管理
- **单例模式**：`get_audio_manager()` 获取全局实例
- **音量控制**：独立的音乐音量和音效音量
- **通道管理**：背景音乐使用独立通道
- **空对象模式**：`NullAudioManager` 处理初始化失败情况

### 4. 粒子系统技术

#### 4.1 粒子属性
| 属性 | 类型 | 说明 |
|------|------|------|
| 位置 | (x, y) | 粒子坐标 |
| 速度 | (vx, vy) | 粒子移动速度 |
| 颜色 | (r, g, b) | 粒子颜色 |
| 大小 | float | 粒子半径 |
| 生命周期 | int | 剩余帧数 |
| 透明度 | int | 0-255 |
| 收缩速度 | float | 大小衰减速率 |

#### 4.2 粒子效果类型

| 效果 | 触发条件 | 颜色 | 粒子数 | 生命周期 |
|------|----------|------|--------|----------|
| **引擎尾迹** | 飞船移动 | 蓝、浅蓝、深蓝 | 2 个/帧 | 20-40 帧 |
| **爆炸效果** | 陨石摧毁 | 橙、黄、红 | 15-25 个 | 30-60 帧 |
| **碰撞效果** | 飞船碰撞 | 红、深红、橙、黄 | 25-50 个 | 40-80 帧 |

#### 4.3 渲染技术
- **`SRCALPHA` Surface**：每个粒子创建独立的透明 Surface
- **圆形绘制**：`pygame.draw.circle()` 绘制圆形粒子
- **alpha 颜色**：直接使用 `(r, g, b, a)` 格式

### 5. 数据结构与设计模式

#### 5.1 数据结构

| 用途 | 数据结构 | 示例 |
|------|----------|------|
| 实体管理 | `list` | `self.meteors`, `self.bullets`, `self.particles` |
| 配置存储 | `dict` | `POWERUP_CONFIG`, `METEOR_CONFIG` |
| 状态管理 | 类实例属性 | `self.lives`, `self.score`, `self.has_shield` |
| 音频数据 | `array.array('h')` | 16 位有符号整数音频样本 |

#### 5.2 设计模式

| 模式 | 应用场景 | 实现方式 |
|------|----------|----------|
| **单例模式** | 音频管理器 | `get_audio_manager()` 函数 |
| **空对象模式** | 音频系统降级 | `NullAudioManager` 类 |
| **组件化设计** | 游戏系统分离 | ComboSystem, DifficultySystem 等独立类 |
| **工厂模式** | 粒子创建 | `create_explosion()`, `create_collision()` 等方法 |
| **状态机模式** | 游戏状态管理 | `game_started`, `paused`, `game_over` 标志 |

### 6. 文件 I/O 技术

#### 6.1 最高分持久化
```python
# 读取
with open("high_score.txt", "r") as f:
    self.high_score = int(f.read().strip())

# 写入
with open("high_score.txt", "w") as f:
    f.write(str(self.high_score))
```

#### 6.2 资源文件查找
- 多路径尝试：当前目录 → 父目录 → 项目根目录
- 自动回退：文件不存在时使用合成音效

### 7. 技术亮点总结

| 亮点 | 说明 |
|------|------|
| **零资源依赖** | 完全使用代码生成音频，无需外部资源文件 |
| **参数化音频合成** | 11 种不同音效通过波形参数化生成 |
| **模块化设计** | 各系统独立封装，便于维护和扩展 |
| **降级机制** | 音频初始化失败时自动使用 NullAudioManager |
| **性能优化** | 粒子系统使用批量更新和列表推导 |
